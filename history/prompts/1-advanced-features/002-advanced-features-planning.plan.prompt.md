## Prompt

# plan.md

Project: In-Memory Console-Based Todo App
Phase: Advanced
Methodology: Spec-Driven Development (SDD)
Tool: Claude Code + Spec-Kit Plus
Language: Python 3.13
Storage: In-Memory Only

## Objective
Implement advanced intelligent todo features using **specs only**.
All code must be generated by Claude Code. Manual coding is not allowed.

## Scope
Included:
- Recurring Tasks (daily / weekly / monthly)
- Due Dates with optional time
- Reminder states (upcoming, due today, overdue)

Excluded:
- Persistence (files / database)
- GUI or web interface
- AI chatbot
- Notifications
- Cloud or Kubernetes deployment

## Execution Plan
1. Define or refine `sp.specify`
2. Generate implementation using Claude Code
3. Validate behavior against spec
4. Refine spec until output is correct

## Task Model (Extended)
- id
- title
- completed
- due_date
- due_time (optional)
- recurrence
- last_completed_at
- reminder_state

## Console Rules
- Text-based interaction only
- No background jobs
- All logic evaluated at user action time
- Clear prompts and error messages

## Definition of Done
- All advanced features implemented
- Code generated only from specs
- In-memory constraint respected
- Ready for Phase III (AI integration)
