## Prompt

# task.md

Project: In-Memory Python Console-Based Todo App
Phase: Advanced
Methodology: Spec-Driven Development (SDD)

## Objective
Implement an advanced in-memory, console-based Todo application **entirely via specs**, with all code generated by Claude Code.

## Application Tasks

### Core (Prerequisite)
- Maintain in-memory task list
- Support clean console interaction
- Ensure deterministic behavior

### Advanced Features
- Recurring Tasks
  - Daily / Weekly / Monthly recurrence
  - Auto-regenerate task after completion
- Due Dates & Time
  - Assign due date (YYYY-MM-DD)
  - Optional due time (HH:MM)
- Reminder States
  - upcoming
  - due today
  - overdue

## Task Rules
- No file or database persistence
- No background jobs or schedulers
- All logic evaluated on user actions
- Console-only input/output

## Data Model Requirements
Each task must support:
- id
- title
- completed
- due_date
- due_time (optional)
- recurrence
- last_completed_at
- reminder_state

## Constraints
- No manual coding
- No GUI, web, or AI chatbot
- No notifications
- Specs must fully define behavior

## Completion Criteria
- All advanced features work as specified
- Code generated only from specs
- In-memory constraint respected
- Ready for Phase III (AI integration)

Status: Ready for execution
